## Why

JL Correa Madeiras scores 47.5/100 in the benchmark — classified as "Fraco" among 20+ lumber yards in Grande Florianopolis. The site is built with WordPress + Elementor and has a clean, modern layout (UI: 11.2/15), but critical structural problems drag every other score down:

- **27 of 28 images lack alt text (96%)** — second worst in the entire benchmark, devastating for SEO and accessibility
- **Title tag EMPTY** in the HTML source — Google cannot properly index the site
- **Meta description ABSENT** — zero control over search result snippets
- **ZERO forms** — the only conversion path is WhatsApp; no quote request, no contact form
- **Zero JSON-LD structured data** — no LocalBusiness, no Product schema
- **22 H2 tags, many decorative** — "Ligue", "WhatsApp", "Segunda a Sexta" are not semantic headings
- **Single-page with no indexable sub-pages** — zero long-tail SEO potential
- **7 H1 tags** — heading hierarchy is broken; crawlers cannot determine page topic

Despite these problems, the business has strong content worth preserving: 50+ years in market (since 1974), 3-generation family history, environmental certifications, clear mission/vision/values, established WhatsApp presence with 8 references, and a gallery of 24+ product photos.

## What Changes

- Restructure the single-page site into a multi-section prototype with proper semantic HTML and heading hierarchy.
- Fix all 27 images missing alt text with descriptive, keyword-relevant alternatives.
- Add title tag: "JL Correa Madeiras — 50 Anos em Palhoca | Madeiras Certificadas".
- Add meta description targeting local search intent for Palhoca and Grande Florianopolis.
- Add JSON-LD structured data for LocalBusiness and Product types.
- Reduce 7 H1 tags to exactly 1; reduce 22 H2 tags to ~6 semantic section headings.
- Add a quote request form with fields: name, phone/WhatsApp, product interest, quantity, intended use, message.
- Add contextual WhatsApp links that prefill messages with product/page context.
- Create product category pages (or sections) for: Madeiras Certificadas, Aberturas, Pinus Tratado.
- Add click-to-call links on all phone numbers.
- Keep the existing visual identity (Elementor layout is already clean) but improve structure.
- Keep e-commerce checkout, online payment, and customer accounts out of scope.

## Capabilities

### New Capabilities

- `modern-responsive-site`: Defines the restructured layout, navigation, hero section, product showcase, and multi-section architecture replacing the flat single-page structure with broken heading hierarchy.
- `seo-and-discoverability`: Defines alt text for all 27 images, semantic heading hierarchy (1 H1, ~6 H2), metadata, structured data, and crawlability requirements to fix the 9.3/19.5 SEO score.
- `conversion-and-lead-capture`: Defines quote forms, enhanced CTAs, WhatsApp integration with product context, and lead capture flows to replace the current zero-form, WhatsApp-only conversion state.

### Modified Capabilities

- None.

## Impact

- Preserves the existing Elementor visual design language — the UI score (11.2/15) is already competitive.
- Requires adding alt text to all 27 images currently without it.
- Requires adding a quote/contact form — currently zero forms exist on the site.
- Requires restructuring heading hierarchy from 7 H1 + 22 H2 to proper semantic structure.
- Requires confirmation of product catalog details (species available, pricing model).
- Does not require checkout, payment processing, inventory systems, or customer login.
- Expected score improvement: 47.5 -> 70+/100, with major gains in SEO (+10), Conversion (+10), and Recommendation (+5).
