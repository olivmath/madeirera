## Problemas Tecnicos Identificados

- `lang="en-US"` no HTML (deveria ser `pt-BR`)
- Canonical URL usa HTTP (deveria ser HTTPS)
- Certificado SSL pertence a uni5.net — nao cobre esquadriasreitz.com.br
- Servidor retorna ~1023 bytes para crawlers (PHP includes falhando)
- Scripts de IE8/IE9: html5shiv e css3-mediaqueries de URLs HTTP descontinuadas
- Google Fonts carregados via HTTP (nao HTTPS)
- H1 usado em CADA titulo de produto (12+ H1s em uma pagina — deveria ser 1 H1 por pagina)
- jQuery 1.x carregado de HTTP (ajax.googleapis.com)
- Font Awesome carregado de use.fontawesome.com (deveria ser self-hosted)
- Universal Analytics (UA) descontinuado — precisa migrar para GA4
- Zero formularios no HTML retornado ao crawler
- Imagens de produto hospedadas em dominio externo (solucao782.tagx.com.br)
