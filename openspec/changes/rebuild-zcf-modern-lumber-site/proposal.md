## Why

ZCF Madeireira scores 40.5/100 in the benchmark — rated "Fraco" (weak). The site evaluated (madeiratratada.floripa.br) is NOT ZCF's own site — it is a third-party directory/aggregator operated by Agencia G13 that lists multiple lumber businesses. ZCF appears as one card among several (Madeireira Cambirela, Tania Madeiras, Cambirela Madeiras). Critical problems:

- **Not a standalone site** — ZCF has no independent web presence; it exists only as a listing card on a directory page with a truncated 150-character description
- **Zero forms, zero lead capture** — the directory has no forms at all; the only conversion path is a WhatsApp button per listing card
- **No meta description, no H2 headings, no schema.org** — SEO is minimal despite the directory having good geographic keyword coverage (100+ bairros across 5 cities)
- **No product catalog** — despite being a lumber company specializing in treated wood (autoclave), there are zero product pages, zero prices, zero product images
- **Design is dated** — Elementor-based WordPress directory with basic card layout, no product photography, no trust signals

ZCF does have a separate domain (zcfmadeireira.com.br) and an Instagram presence (@zcfmadeireira), but the benchmark evaluates the directory listing. The business has real differentiators: 25+ years in market, industrial autoclave treatment, certified quality, and coverage across Grande Florianopolis.

## What Changes

- Build a standalone site for ZCF Madeireira replacing the directory listing dependency.
- Add a hero section with business positioning: treated wood specialists, 25+ years, Palhoca/Biguacu region, and primary CTA in the first viewport.
- Add a product catalog showcasing treated wood products (decks, pergolados, cercas, casas de madeira, estruturas rurais/urbanas) with descriptions, applications, and photo placeholders.
- Add a quote request form with product context, name, phone, city, and message fields.
- Add semantic HTML structure: H1 per page, H2 sections, image alt text.
- Add meta descriptions, Open Graph metadata, canonical URLs, and JSON-LD structured data (LocalBusiness, Product).
- Add a sticky WhatsApp button with contextual prefilled messages per page/product.
- Leverage the geographic coverage data from the directory (100+ bairros across Florianopolis, Sao Jose, Palhoca, Biguacu, Santo Amaro da Imperatriz) as SEO-optimized service area content.
- Keep the existing contact info (phone 4830585898, WhatsApp 48996041469, address in Guarda do Cubatao, Palhoca) visible in header/footer.
- Keep e-commerce checkout, online payment, and customer accounts out of scope.

## Capabilities

- `seo-and-discoverability`: Defines semantic HTML, metadata, structured data, heading hierarchy, image alt text, and geographic service area pages to capitalize on the 100+ bairro coverage already indexed by the directory.
